Cài Đặt Gemini API Key

Để chạy phân tích và render 3D trực tiếp trên GitHub Pages, bạn có thể nhập Gemini API Key miễn phí từ Google AI Studio.

Hướng dẫn lấy key miễn phí trong 1 phút:

  1. Truy cập aistudio.google.com
  2. Nhấn Get API key $\rightarrow$ Create API key
  3. Dán key vào ô trên và nhấn Lưu Key
